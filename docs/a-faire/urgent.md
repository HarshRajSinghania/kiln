# Urgent

Ce que seul un humain de l'équipe peut faire : un accès à donner, un paiement, une décision, une
action dans une interface. Une case à cocher par action, sous la forme `- [ ] action — pour qui`,
retirée une fois faite. La status line de Claude Code compte les cases ouvertes (« urgent N »).
